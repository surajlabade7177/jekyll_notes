What is "layouts" in Jekyll ?
Ans: In Jekyll, layouts are templates that define the common structure/design of your pages.
     Layouts are nothing but the skeleton of HTML code that we can used to defined look and fill of different types of pages in website.

NOTE : We can craete a seperate _layouts folder and inside it we can define the layouts there.
